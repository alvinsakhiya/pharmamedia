## Overview

PharmaMedia is a cloud-native multimedia asset management platform designed for storing, organising, managing, and sharing pharmacy-related digital assets through a modern responsive web application.

The platform demonstrates the practical implementation of scalable cloud-native architecture using Microsoft Azure services, RESTful CRUD workflows, CI/CD deployment pipelines, and responsive frontend technologies.

PharmaMedia supports enterprise-style multimedia management for:

- Medication Images
- SOP Documents
- Training Media
- Packaging Assets

## Azure Cloud Architecture

PharmaMedia leverages multiple Microsoft Azure cloud services to provide scalable deployment and multimedia management capabilities.

| Azure Service | Purpose |
|---|---|
| Azure App Service | Frontend application hosting |
| Azure Blob Storage | Multimedia file storage |
| Azure Cosmos DB | NoSQL metadata database |
| Azure Logic Apps | RESTful CRUD workflows |
| Application Insights | Monitoring and telemetry |
| GitHub Actions | CI/CD deployment automation |

## Scalability

The platform was designed using scalable managed Azure services capable of supporting large multimedia datasets and distributed cloud-hosted operations.

Azure Blob Storage and Azure Cosmos DB provide scalable infrastructure capable of handling increasing storage demands and metadata growth efficiently.

Managed cloud services also reduce operational overhead while improving deployment flexibility, scalability, and maintainability.

## DevOps & CI/CD

The project repository is connected directly with GitHub Actions and Azure Deployment Center.

Whenever changes are pushed to the main branch, GitHub Actions automatically deploys the updated application to Azure App Service.

This demonstrates modern DevOps workflows and continuous integration/continuous deployment practices.
